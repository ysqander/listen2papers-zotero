# Changelog

## v0.1.0 - 2026-06-03

- Initial public release.
- Adds `Listen in listen2papers` to Zotero item context menus.
- Uploads one selected local PDF attachment to listen2papers.
- Supports scoped, revocable listen2papers plugin tokens.
- Sends available Zotero metadata with the upload.
- Opens the created listen2papers reader URL after upload.
- Includes Zotero 7.0 through 9.0.* compatibility declarations.
